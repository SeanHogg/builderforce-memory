Convert a Mamba checkpoint → MBJS

Tool

What this does

Mamba (state-spaces/mamba-*), Falcon-Mamba and Codestral-Mamba checkpoints are state-space models like this engine's. This converter ports their .safetensors weights with the engine's own importer and writes the MBJS binary format (with a CRC-32 integrity trailer).

Transformers (Qwen2.5-Coder and the like) cannot be converted at any tensor naming — attention has no state-space counterpart; distillation is the only route. Needs a browser with WebGPU (the model is built on the GPU to write the checkpoint).
Vocabulary: a checkpoint keeps its own tokenizer's vocabulary (state-spaces/mamba: GPT-NeoX, 50,277 tokens). To pair it with another tokenizer — mambacode.js uses Qwen2.5-Coder, 151,936 tokens — set the target size below: missing rows are initialised small and random, surplus rows dropped. Run a few passes through pretrain.html afterwards to warm up new token slots.
